# وب‌سایت حمیدرضا

یک قالب فارسی راست‌چین و واکنش‌گرا با تم فناوری (سرمه‌ای، آبی نئونی و فیروزه‌ای) برای انتشار در GitHub Pages.

## انتشار با GitHub
1. وارد GitHub شوید و یک repository جدید بسازید.
2. فایل `index.html` را در ریشهٔ repository آپلود کنید.
3. در Settings → Pages، گزینهٔ Deploy from a branch را انتخاب کنید.
4. شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب و Save کنید.
5. پس از چند دقیقه، آدرس سایت در بخش Pages نمایش داده می‌شود.

## پنل مالک — نکتهٔ امنیتی بسیار مهم
این نسخه فقط نمونهٔ نمایشی سمت مرورگر است:
- رمز آزمایشی: `demo1234`
- رمز در کد قابل مشاهده است؛ پس برای محافظت واقعی مناسب نیست.
- محتوا و فایل‌ها فقط در همان مرورگر ذخیره می‌شوند و به GitHub یا سرور آپلود نمی‌شوند.
- برای پنل واقعی باید ورود امن و آپلود را با سرویس سمت سرور یا Firebase Authentication + Cloud Storage پیاده‌سازی کنید و قوانین دسترسی را محدود کنید.
- هرگز رمز اصلی، کلید خصوصی یا اطلاعات محرمانه را داخل کد فرانت‌اند یا GitHub قرار ندهید.
